
# Vintage Go-Kart Restoration & Electromechanical Integration

**Independent Engineering Project | Mechanical Fabrication • Electrical Integration • Automotive Systems**

## Project Overview

Restored a deteriorated "facebook marketplace" 1980s go-kart and upgraded its drivetrain, braking system, chassis, and electrical accessories. The project involved hands-on fabrication, mechanical troubleshooting, component selection, and integrating multiple systems into a functioning vehicle.

**Result:** Approximately 46 mph GPS-measured top speed.

## Initial Condition and Objectives

The go-kart was acquired with a heavily rusted chassis and a nonfunctional drivetrain on facebook marketplace for $100.

My objectives were to:
- Restore the chassis to a working and safe condition.
- Convert the original single-wheel-drive "one wheel peel" setup to a solid live rear axle.
- Upgrade braking performance (replacing the outdated cable drum braking system).
- Integrate electrical accessories.
- Improve reliability through fabrication and troubleshooting.

## Mechanical Fabrication

### Drivetrain Conversion
- Removed the original drivetrain components.
- Converted the rear drivetrain to a solid 1-inch live axle.
- Welded bearing supports to accommodate the new axle configuration.

### Chassis Modifications
- Welded structural cross-bracing.
- Fabricated front and rear bumpers.
- Reinforced mounting areas to support the modified drivetrain.

### Braking System
- Replaced the original cable-operated drum brake with a hydraulic disc-brake system.
- Fabricated a custom mounting bracket for the brake caliper.
- Adapted a 6-inch brake rotor to the rear drivetrain.

## Electrical Integration

- Integrated a 16V drill battery with a DC-DC converter to supply 12V lighting.
- Installed manually operated dashboard switches.
- Added an ignition kill switch that grounds the ignition circuit.
- Retrofitted a bicycle speedometer using axle rotation to estimate vehicle speed.

## Engine and Performance

- Integrated an upgraded 212cc OHV Horizontal-Shaft Gas Engine.
- Modified the engine with a performance slide carburetor and governor removal.
- Recorded an approximately 46 mph top speed using GPS.
